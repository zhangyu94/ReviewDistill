# Product spec

ReviewDistill distills the comments you write in a LaTeX paper into an evolving label taxonomy and a reusable agent skill.

This folder is the contributor product spec. Each file is a topic with its own headings. User-facing guides live on the documentation site.

| File | Job |
| --- | --- |
| [overview.md](overview.md) | What it is, goals, non-goals, success |
| [workflow.md](workflow.md) | Init, extract, label, accumulate |
| [taxonomy.md](taxonomy.md) | Labels, evolution, AI coding |
| [extract.md](extract.md) | Harvest, context, git; pairing is [comment-identity.md](comment-identity.md) |
| [ui.md](ui.md) | Workbench, taxonomy view, evolution view |
| [cli-and-export.md](cli-and-export.md) | CLI and skill export |
| [storage.md](storage.md) | JSONL home folder, local-first |
| [data-schema.md](data-schema.md) | Stored columns and JSONL rows |
| [comment-identity.md](comment-identity.md) | New, revision, move, gone; Verify vs Delete |
