# History

Header **History** lists taxonomy and labeling events you can **Undo** and **Redo**. Expand a row for the extra sentence, comment text, or saved definition.

Typical events: assigning a label, Label with AI, fork, Verify / Delete, nesting or merging, flattening or removing a subtree, renaming, parking comments on `ungrouped`.

Extract updates to comment wording are source updates, not undos. Use History when a suggestion or a drag went to the wrong label.
